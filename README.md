## 三网回程走 AS9929，实际延迟和路由是什么样

三网回程全部进 AS9929，去程各走各的。国内平均延迟 179ms 是双ISP-9929 那台测出来的，对美西机房算合格，比 CN2 GIA 高，但在美国双 ISP 套餐里属于延迟最低的一档。

VPS小学生 测的 55 元双ISP-9929 路由是这样：电信去程经圣何塞直连洛杉矶，回程借道联通 AS9929 直连；联通去程走自家 AS4837 经圣何塞机房，回程 AS9929；移动去程经圣何塞到洛杉矶，回程同样 AS9929。他的原话是「三网往返直连，三网回程强制走联通AS9929优化线路，除了三网CN2 GIA，这应该是最好的美西线路了」。这句是他的评价，不是我的结论。同一台机器的带宽测试，国内外上传下载基本跑满 200M，上传还能多跑一点。

laoliublog 测的两台是另一回事，数据得分开看。48 元的 LA-9929-80M 那台，Geekbench 5 单核 497、多核 495，IO 磁盘 283.3MB/s，回程 traceroute 显示路径为 AS10099 美国联通 → 上海进入 AS9929 → 转电信 AS4134、联通 AS4837/AS17816、移动 AS9808 落地。落地延迟：广州电信 155.96ms、上海电信 135.64ms、北京电信 157.47ms、广州联通 161.33ms、上海联通 136.80ms、北京联通 154.06ms、广州移动 287.70ms、北京移动 176.99ms。移动明显比电信联通高一截，广州移动接近 290ms。

50 元的原生9929 新段那台，Geekbench 5 单核 648、多核 623，比上面那台高不少，IO 282.3MB/s。回程同样是 AS10099 → AS9929 → 电信 AS4134 / 联通 AS4837 / 移动 AS9808，上海电信末端 138.84ms，广州联通 161.50ms，上海联通 138.45ms，北京联通 157.24ms。北京移动末端出现了 271.43ms 的节点，走移动线路的话要有心理准备。

## 几条短板，以及哪些人别买

38 开头的 IP 纯净度在下滑。VPS小学生 的原话：「唯一的缺点是38开头的IP现在纯净度已经开始有点差了，但是还是比原来154开头的IP要干净很多，越早入手越容易买到更干净的IP」。他还提到几个平台对纯净度的判断差别很大，有认为很干净的，有认为有点风险的，大部分脚本判为美国原生家庭 IP。买之前最好自己拿 IP 去查一遍。

产品名和实际机房可能对不上。laoliublog 测「美西原生9929线路（新）」时，机器实际开在美国华盛顿机房，他自己的吐槽是「好奇的是华盛顿在美国东北部，不是在美西哦」。这不代表所有 9929 套餐都这样，LA-9929 那档写的就是洛杉矶机房。下单前问清落点，不要默认名字里的「美西」等于洛杉矶。

官方页面有两条硬性限制。双向9929 商品页写着「严禁公共代理！」；官网还特别申明「如果不为服务器设置高强度密码，请不要购买本站产品！」。买来搭公共代理或者懒得设密码的，这条线不适合你。

1G 内存干不了重活。装完面板只剩 547M，跑 Docker、数据库、视频转码都会卡。双 ISP 属性用来建普通站也是浪费，这项配置的价值在 IP，不在机器。

还有一个容易被忽略的风险，出现在二手过户上。二手市场流通的同名机器，平台会提示「原卖家可能仍掌握 SSH 密钥、系统密码或其他远程访问方式」，过户只变更六六云账号归属。真要走这条路，接手第一件事是重装系统、换掉全部登录凭证。

## 常见问题

### 六六云9929 支持支付宝吗

支持。VPS小学生 的测评配置单里明确写了 55 元/月那档支持支付宝。

### 能拿来跑 TikTok 直播吗

按 VPS小学生 的测试，双ISP-9929 那台本地移动带宽看视频有 9 万+ 的速度，他的判断是「用来做Tiktok直播已经绰绰有余」。实际直播还取决于你的推流码率、本地网络和账号状态，机器只是一环。

### 需要自己装 BBR 吗

看档位。双ISP-9929 那台用的是六六云后台系统自带的 BBR，不用额外装。官网的商品表里，原生9929（新）和英国原生IP 都标了「自行安装bbr加速」，英国那档还写了「重装系统后切记要安装bbr」。下单前看清楚自己那一档的说明。

### 三网回程是不是都走 9929

9929 这条线上是的，电信、联通、移动回程都进 AS9929。唯一的例外是 80 元那档「2H2G 高配 · 三网回程 CN2」，它走的是 CN2 精品线路。
